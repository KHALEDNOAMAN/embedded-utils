A comprehensive collection of robust, dependency-free utilities for embedded systems running Node.js or TypeScript/JavaScript environments.

## Installation

`ash
npm install @khalednoaman/embedded-utils
`

## Features

- **CRC Calculation:** Fast CRC8, CRC16, and CRC32 using lookup tables.
- **Ring Buffer:** Lock-free, generic ring buffer with iterator support.
- **Bit Manipulation:** Efficient bit extraction, setting, clearing, toggling, and byte swapping.
- **State Machine:** Lightweight Finite State Machine with transition guards and callbacks.
- **Protocol Parser:** Event-driven streaming binary protocol parser.
- **Software Timers:** Manage multiple software timers efficiently.
- **Byte Converters:** Convert between standard types and byte arrays seamlessly.
